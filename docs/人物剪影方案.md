# 人物剪影方案：C 为基准，时代决定画法

## 用户决定

2026-10-26，用户要求调整人物形象与步态，以剪影凸显劳动人民的感觉；用内置 imagegen 生成 A 木刻、B 剪纸、C 水墨、D 极简四种效果图后，用户指定：

> 默认使用C，在穿越到不同时代时，风格跟随相应时代变化。

因此本轮先修订阶段 1 的人物，不视为用户已经验收原有步态或进入阶段 2。全片原目标、24 段时间结构和分阶段反馈方式继续保留。

## 不随时代改变的部分

- 采用 C 的普通劳动者气质：身形厚实、肩背有分量、手掌与小腿饱满，姿态平静、自然，不作英雄式摆拍。
- 以实心形体构成人物，不再使用空心躯干、眼睛细节和细线四肢。
- 侧脸、身体比例和全部关节数据保持一致。服饰和笔触沿画框截面换风格，不重新计算一套步态。
- 保留赭色衣料小标记；汉代拓片与近代灰阶段将它相应灰阶化，避免破坏材料语言。
- 图稿只作参考，影片继续使用纯代码图形，不把 AI 图稿平移当成走路。

## 步态修订

世界位移继续为每秒 200 个逻辑单位，每 0.5 秒一步，与 120 BPM 同步。足部支撑占单脚周期的 60%，左右交替时有短暂双脚支撑。

以前骨盆长期处于偏低的位置，即使支撑脚已固定，人物也容易呈现持续蹲行的观感。本轮依据两只脚踝的位置和腿长约束决定骨盆高度，让承重腿接近伸展，同时保证摆动腿也能到达其目标位置。

摆动脚抬高峰值降到 24 个逻辑单位，并使用平滑的抬落曲线。鞋形与脚踝加入脚掌滚动：落脚时脚跟先接触，随后全掌承重，离地前抬起脚跟、前掌蹬离。支撑点的世界坐标保持固定，脚掌滚动不依靠整体平移。手臂摆幅收敛，衣摆小幅响应步态。

## 时代适配

`src/rig/appearance.js` 为各段配置人物的绘画材料、主色、衣摆、发式轮廓与识别色位置；`src/rig/silhouette.js` 从同一骨骼绘制人物。

| 时代组 | 人物画法方向 |
| --- | --- |
| 旧石器、新石器 | 赭色岩画颗粒、陶纹式炭黑色块 |
| 商周、战国、秦 | 青铜斑点、帛画平面色、陶土颗粒 |
| 汉 | 浅色反白剪影与拓片颗粒 |
| 魏晋、隋唐 | 淡墨块面、矿物色壁画式剪影 |
| 宋元 | 深浅墨色、稀疏水痕、枯笔与留白 |
| 明、清 | 木刻细刀痕、设色长卷式色块 |
| 晚清、民国 | 石印排线、灰阶默片式实心形体 |
| 新中国早期、改革开放、今天 | 套色、局部像素纹理、清晰数字色面 |
| AI、智械、共生 | 浅金线、精细刻线、柔和纤维纹理 |
| 太空、星际 | 在深色背景上用浅色剪影和工程线／点刻，保持可读 |
| 山河新生 | 回到墨色形体，叠入少量细金线 |

以上为人物风格适配草案。背景依旧是阶段 1 结构占位；不宣称已完成最终服饰考证或各段精致美术。

## 验证与交付

- 单元检查保留累计时间、支撑点固定、腿长与跨框连续、触地事件及结尾未落脚；新增脚跟触地到前掌蹬离的检查。
- 任意跳转确定性检查覆盖旧石器、汉、宋、现代、未来与展墙。
- `node tools/review-character.mjs` 生成 `out/character-c/character-review.mp4`（12 秒：旧石器、北宋、山河新生各 4 秒，全景与人物近景并列）及 `era-silhouettes.png`（24 段人物对照，保持原比例）。
- `npm run capture -- --out out/character-c` 生成新步态图和全片接触表。原 `out/stage-1/` 视频保留为初版对照；新人物全长视频另存，避免混淆。

本轮自检：6 项动作与时间轴测试通过；15 个乱序跳转点的画面逐像素一致；浏览器操作检查覆盖拓片与未来段跳转、骨骼检查、播放和暂停。实际导出近景预演 12 秒／360 帧，全长 191 秒／5730 帧，均为 1920 × 1080、30fps、无声 H.264。正式输出帧率仍待后续确认。
