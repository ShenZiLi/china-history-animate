## 共用约束

- 代理只编辑自己的场景模块、图层目录和美术简报，不覆盖共用骨骼、时间轴、镜头或别的场景。
- 统一主体为已确认的 C 剪影；生成环境图层中不出现人物、车辆、自行车、轮子或骑行动物，以免与代码行者冲突。
- 图层为本地文件，通过 `src/kit/media.js` 统一预载。画面 ready 后才允许截图或逐帧渲染，不依赖运行时网络。
- 环境分为背景、透明前景及必要的云雾／光照层；代码驱动视差、水、火、雾、粒子、小动作、步态与穿框，不能以静态图片平移代替走路。
- 画面用 16:9 正确比例输出；实体道路在共同支撑平面衔接。AI 图层的画面不能改动支撑脚约束。
- 每个代理交付自己的提示词、素材路径、资料依据、动效说明和截图，主代理做连续转场、任意跳转、接触表与视频审看。
- imagegen 素材进入影片是本轮用户新增授权；原提示词中的纯代码绘制技术方向以此更新，但连续行走、单一主角、历史表达与未来地面道路要求仍然有效。
