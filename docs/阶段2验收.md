## 实际画面与动作

- **旧石器：**粗粝岩壁、洞口远山、微小远坡兽群，暖光与洞外冷色形成空间。程序火焰、余烬、粉尘、触地脚印与约 1.78 倍共用骨架投影；主角低头，影子头部延迟 0.25 秒。天然立石出口接入红黑彩陶纹带。
- **北宋：**主峰偏右的原创巨碑式山水、分层积墨、细瀑、云气和松石前景。行者从约 0.22 倍逐步推近至 0.44 倍，始终可在路上找到。地形包含 18 个逻辑单位高的小石，56 秒真实落脚在石面；入口松石与木廊桥出口各有独立精细图层。
- **山河新生：**平远河网、低缓青绿山脊、未来台地庭院、维护中的古桥和小型山脊通信设施。独立水光、前后景视差、光线呼吸与星图化河网；五种铺装记忆按序温和出现，172 秒真实触地后留下土面脚印，幼苗已在旁边。8–10 秒退向纸白，薄纸框引出下一步。
- **共同人物：**继续使用已验收的 C 剪影骨架、侧脸与身形。衣摆、发式轮廓、灰阶与材料变化不改同一时刻的关节坐标；跨框剪影不跳位。

## 合成与转场修正

精作场景不再分割成几条窄色带。活动场景保持完整，邻场只在靠近画框的半侧替换材料。场景先在独立缓冲层完成绘制，再由主层统一合成，避免子场景的透明度设置覆盖转场透明度、产生阶梯状矩形。

框截面前后共用同一个人物姿势和相机投影。北宋远景变化向相邻两段平滑接回，支撑点和石头共享世界坐标。末段离开时保留道路触感，展墙使用代表性画面定格，镜头先从实际纸白出口进入画廊，避免第 24 格也成为另一张空白纸。

## 自检证据

- 10 项测试通过：累计时间、脚步周期、足底锁定、腿长约束、结尾未落脚、脚掌滚动，及跨石地形、镜头跨段连续、影子半拍错位、五种道路记忆。
- 33 个时间点经乱序跳转后，重复画面的 PNG 哈希一致；9 个图层全部 ready 后才进入渲染。
- 三个选定的环境区域避开主角，比较相差 0.2 秒的画面，均有像素变化；结合代码与动态片段检查火、水、雾和视差，未以静态人物平移冒充走路。
- 实际预览操作检查北宋与山河新生的章节跳转、进度拖动、播放／暂停；浏览器输出无页面异常。
- `npm run build` 通过。媒体信息以实际 ffprobe 检查为准，正式输出帧率仍待后续确认；本阶段使用 30fps 便于审阅。
