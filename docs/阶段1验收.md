- `compare-30fps.mp4`、`compare-60fps.mp4`：相同的第 8—12 秒，包含镜头平移、摆腿和第 11 秒穿框。

| 支撑脚不滑动 | 支撑阶段足部世界坐标恒定；膝盖由两段腿长求解。测试覆盖完整主体时段、两个足部和跨框边界。 |
| 穿框连续 | 截面两侧采用同一个 `poseAt(t)`，仅切换材质与服饰参数。测试检查所有段起点前后足部位置；第 8—12 秒动态对比可检查实际穿框。 |

## 自检记录与边界

- `npm test`：5 项通过，覆盖累计时间、支撑脚固定、腿长约束与跨框连续、触地事件，以及最后抬脚不落地。
- `npm run build`：通过。p5.js 主库较大，打包器给出体积提示；没有影响构建或本地运行。所有依赖通过锁文件固定，预览无需远程媒体。
- `npm run verify`：15 个乱序时间点逐像素一致，24 段可寻址，展墙符合尺寸限制，无浏览器异常。
- 已逐张检查全片接触表与步态图，修正标题在相邻深浅背景上的对比度。
- 完整 MP4 的解码检查用于发现损坏帧；不能替代后续阶段的完整审片。本轮没有把结构占位视为完成的历史美术。
- 30fps 是便于审阅的结构导出；同段 60fps 将镜头单帧位移减半。正式帧率仍待对比反馈后确认。

## 本次反馈重点
