# 《一步千年》—— One Step, A Thousand Years

一个人，一条路，走过中国的过去、今天与未来。

全片 **3 分 11 秒（191 秒）· 1920×1080 · 30fps · 120 BPM**，由 JavaScript 逐帧绘制、程序合成配乐，**不使用任何外部图片、影片、音频素材**。唯一的主角始终徒步从左向右行走；每跨过一道画框，时代、衣着、建筑、路面、绘画材料与音色随之改变。

> 创意核心：**脚步没有停，脚下的土地已经走过千年。**

## 快速开始

无需构建工具，也无需安装依赖（p5.js 已随仓库提供）。

```bash
# 1. 本地预览
node tools/serve.mjs
# 打开 http://127.0.0.1:8931/

# 2. 只渲染音频
node tools/render-audio.mjs

# 3. 逐帧渲染 + 合成成片（需要 ffmpeg）
node tools/render-frames.mjs --fps=30
node tools/build-video.mjs

# 4. 场景检查表（24 格静帧）
node tools/shot.mjs "tools/gallery.html" build/gallery.jpg
```

播放器操作：`空格` 播放/暂停，`← →` 单秒，`Shift + ← →` 五秒，`0` 回到片头，进度条可拖动。

## 设计要点

- **一个 t 决定一切。** `renderFrame(ctx, t)` 是纯函数：同一时刻永远得到同一画面，可任意跳转、逐帧导出。
- **走路不滑步。** 支撑脚在触地期间相对世界坐标静止；人物位移与地面滚动共用同一个相位积分，`STRIDE = 84px`、一拍一步。高光处的减速同时作用于步态与地面，不会出现"停步后继续滑行"。
- **画框从场景里长出来。** 洞口岩体、陶器口沿、青铜方框、竹简、门阙、桥洞、月洞门、相纸、胶片框、机械拱架、叶片廊顶、圆形石门……过框时下一时代从框内透出，人物框外旧画风、框内新画风。
- **材料不同，不只是滤镜。** 岩画、彩陶、青铜浮雕、竹简、画像石、人物线描、唐代设色、北宋巨碑山水、南宋一角山水、元代干笔、明代版画、石印、默片、木刻套色、像素、数字插画各有一套独立的造型与笔触逻辑。
- **音乐是同一支主题。** 五声音阶（D 宫）的 8 小节旋律贯穿全片，各段只换音色、织体与混响；脚步按真实触地事件触发，材质随路面变化。

## 边界与声明

- 史前场景属于合理艺术想象；历史时期的服饰、建筑与器物按"普通行旅者"的可理解形象设计，不宣称考古复原。
- 未来六段为**虚构文明阶段**，年份只用于建立时间跨度，不是技术预测；每段均标注"艺术想象 / Speculative"。
- 全片不出现自行车及任何骑行动作；主角不骑马、不乘车、不乘飞行器。
- 现代与未来界面、标识、提示音均为原创虚构设计，不使用真实品牌。
